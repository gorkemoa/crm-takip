# Code of Conduct

Bu toplulukta herkese saygili, yapici ve profesyonel iletisim beklenir.

## Beklenen Davranislar

- Saygili dil kullanimi
- Yapici geri bildirim
- Yeni katkicilara yardimci olma
- Teknik tartismalarda kisisellestirmeden kacınma

## Kabul Edilemez Davranislar

- Hakaret, asagilama, tehdit
- Ayrimci veya taciz edici soylem
- Kisisel bilgi ifsasi
- Toplulugu sabote eden davranislar
